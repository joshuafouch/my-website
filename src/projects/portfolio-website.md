# My Portfolio Website

A modern, responsive portfolio website built with SvelteKit and styled with TailwindCSS.

## About This Project

This website serves as both my personal portfolio and a technical blog where I share my thoughts, projects, and experiences in software development.

## Key Features

- **Modern Stack**: Built with SvelteKit 2.0 for optimal performance
- **Beautiful Design**: Styled with TailwindCSS and DaisyUI components
- **Dark Theme**: Nord-inspired dark color scheme
- **Blog System**: MDsveX integration for markdown-based blog posts
- **Project Showcase**: Dedicated projects page with detailed project descriptions
- **Responsive**: Mobile-first design that looks great on all devices
- **Type-Safe**: Full TypeScript support throughout

## Technical Implementation

### Frontend Framework

The site is built using SvelteKit, which provides:

- Server-side rendering (SSR)
- Static site generation (SSG)
- Optimized routing
- File-based routing system

### Styling

TailwindCSS with DaisyUI provides:

- Utility-first CSS framework
- Pre-built UI components
- Consistent design system
- Nord dark theme customization

### Content Management

MDsveX enables:

- Markdown-based content
- Syntax highlighting with Shiki
- Table of contents generation
- Frontmatter metadata

## Deployment

Deployed on Vercel with automatic deployments from the main branch.
